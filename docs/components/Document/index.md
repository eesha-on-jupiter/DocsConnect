# Document

| Component | Description |
|---|---|
| [Get Document](GetDocument.md) | Fetches a document by ID, or resolves a document by name via the Drive API and fetches it. |
| [Create Document](CreateDocument.md) | Creates a new empty document with a given title. |
| [Batch Update Document](BatchUpdateDocument.md) | Applies a batch of edit requests to an existing document in one call. |
| [Clear Document](ClearDocument.md) | Deletes all content from a document's body, leaving it empty. |
| [Create Header](CreateHeaderJson.md) | Creates a document's header segment, optionally inserting initial text into it. |
| [Create Footer](CreateFooterJson.md) | Creates a document's footer segment, optionally inserting initial text into it. |
| [Create Footnote](CreateFootnoteJson.md) | Creates a footnote reference, appended at the end of the document's body, optionally inserting initial text into its segment. |
| [Update Document Style](UpdateDocumentStyleJson.md) | Updates document-wide style properties such as page margins, page size, and background color. |
